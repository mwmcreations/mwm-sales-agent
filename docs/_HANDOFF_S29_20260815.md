Added by this session, each paid for once:

- 🔴 **Ship the instrument WITH the feature, not after it.** S28 went live and a
  real drag did not apply, and nothing anywhere could say why — no Slack, no
  error, no counter. Reconciliation could see the drift; the sync could not be
  questioned. #99 turned that into an answer in ninety seconds. Twelve hours
  earlier #97 had fixed *exactly this* in the lead rows. Same defect, same
  night, same hand.
- 🔴 **Read what the server SENDS, not what the browser SHOWS.** `/studio-hour/`
  looked compliant for months and was only made so by JavaScript at runtime; the
  served HTML still carried an SMS consent checkbox and a `disabled` buy button.
  A fix that only exists after JavaScript is a fix that only exists for humans,
  and the reviewer that rejected us five times is not one. Check with
  `credentials:'omit'`.
- 🔴 **A counter that is read and never written is not a diagnostic.**
  `/health`'s lead-row verdict had two of its four inputs bumped nowhere in the
  codebase. It could only ever answer "idle". Eleven days of a known-wrong
  report, and the instrument built to explain it was blind by construction.
  `test_lead_row_wiring.py` now pins this class shut.
- 🔴 **SCROLL BEFORE YOU ESCALATE.** `Maya Leads Report` was reported frozen at
  Aug 3 for eleven days, through five ERIC checks and a CRITICAL data-integrity
  flag. It was never broken. Row 9 holds one enormous transcript cell, and rows
  10–46 sit below it. The capture works, the write works, the sheet is complete.
  ERIC's whole "the bottleneck is the funnel, not the traffic" conclusion rests
  on a denominator nobody had actually looked at. **Re-derive it before quoting
  it.** (A fix worth doing: clamp the Transcript column so no row can hide the
  ones under it.)
- **An unbounded read is a read with no end.** S28's first tick listed the whole
  calendar with `singleEvents=True`, which expands a never-ending recurring
  series for ever. The thread beat once and sat there *working*. The spec said
  "do not attempt a full-calendar sync" for the 410 path — that one was bounded
  and the first-run one was not. Bound them all.
- **The string you are hunting may not be in the repo.** `"Hi ,"` was not. The
  Meta template holds `Hi {{1}},` and we supplied `{{1}}`; the template was
  fine, the input was an invisible character. `(name or "there").split()[0]`
  is right about `None`, raises `IndexError` on `"   "`, and passes a
  left-to-right mark straight through. Instagram display names are full of them.
- ⚠️ **Railway has TWO services in this project and the obvious one is dead.**
  `mwm-sales-agent` is **offline**; the live service is **`brilliant-success`**,
  which owns `mwm-sales-agent-production.up.railway.app`. Setting an env var on
  the wrong one does nothing and looks exactly like a broken feature.
- ⚠️ **In wp-admin, set form fields by name, not by clicking coordinates.** A
  mis-aimed click on the booking edit screen ticked "Email the client a
  confirmation" instead of landing in the reason box. Caught before saving. On a
